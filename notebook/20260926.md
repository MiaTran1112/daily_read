### Varianc Explained: Understanding the Bayesian approach to false discovery rates (using baseball statistics) (https://varianceexplained.org/r/bayesian_fdr_baseball/)

- sometimes we don’t just want to estimate a value; we want to answer a yes/no question and classify observations into groups.
-> e.g. Which baseball players have a true batting probability greater than .300? This becomes a hypothesis testing / multiple testing problem: if we test many players, some may appear above .300 just by chance.

- PEP (Posterior Error Probability):
    - using each player's posterior Beta distribution, we can calculate the probability that their true batting average is below .300.
    - calculate PEP in R using `pbeta()`
    - Hank Aaron has PEP = 0.169, meaning there is a 16.9% posterior probability that his true batting average is below .300.
    - PIP (Posterior Inclusion Probability) (opposite of PEP):
        - PIP = 1 - PEP
    - lower PEP -> stronger evidence that the player truly belongs above the .300 threshold

- why PEP depends on sample size:
    - a player's shrunken batting average might be .28 but if they have few at-bats, there is still substantial uncertainty that their true average could be above .30.
    - if we have many at-bats, the posterior becomes narrower, so we become more certain about whether they are actually below .30.

- FDR (False Discovery Rate ):
    - Instead of asking whether each individual player is definitely above .300, we can control the expected proportion of false discoveries in the whole selected group.
    e.g. include as many players as possible while expecting no more than 5% of the hall of fame to be incorrectly included.
    - FDR can be made stricter (e.g. 1%) or more relaxed (e.g. 10%) depending on the goal.
    - calculate FDR using PEP:
        - If we select the top players with the lowest PEP, we can add their individual PEPs to get the expected number of false discoveries.
        e.g. top 100 players: FDR = sum(PEP) = 4.43 (this is the expected false discoveries) / 100 = 4.43%
        -> average PEP of the selected group = its expected FDR.
    
- q-value: 
    - Instead of manually checking different cutoffs, sort players by PEP and calculate the cumulative mean PEP: `qvalue = cummean(PEP)` -> tells us the FDR associated with including a particular player and everyone above them in the ranking
    - qvalue < .05 → control FDR at 5%
    - qvalue < .01 → control FDR at 1%

- PEP vs. q-value: 
    - PEP: probability that an individual player is a false discovery.
    - q-value: FDR of the group of players selected up to that point.
