## Variance Explained: Understanding credible intervals (using baseball statistics) (https://varianceexplained.org/r/credible_intervals_baseball/)

- sometimes you want to know more than just our “best guess,” and instead wish to know how much uncertainty is present in our point estimate.
- We normally would use a binomial proportion confidence interval (like a margin of error in a political poll), but this does not bring in information from our whole dataset.

- compute a credible interval using empirical Bayes:
    - after setup: mutate(eb_estimate = (H + alpha0) / (AB + alpha0 + beta0)) -> shrunken estimate: players with few at-bats are pulled toward the overall batting average, while players with lots of data are affected less
    - then update the prior using each player's data to get their posterior beta distribution:
        - alpha1 = H + alpha0
        - beta1 = AB - H + beta0 
        - The posterior represents what we believe the player's true batting average could be after combining the overall data with the player's own performance.
    - credible intervals: a range containing a given percentage (e.g. 95%) of the posterior distribution.
        - calculation in R using `qbeta()`
        - intuition: the interval should reflect how much information we have:
            - few at-bats -> wider interval because we are more uncertain.
            - many at-bats -> narrower interval because we have more evidence about the player's true average.
    - Credible intervals versus confidence intervals: 
        - credible intervals take prior information into account.
        - confidence intervals: treats the true parameter as fixed and does not incorporate prior information in the same way.
        -> With lots of data, the two intervals can become very similar because the player's own evidence dominates the prior.
